## What it does
Forecast electricity, gas and water consumption by meter/site; weather- and occupancy-aware models; budget vs. actuals with anomaly alerts; baselines that feed [Building Efficiency Auditor](https://github.com/Zion-support/building-efficiency-auditor) savings validation and [Solar ROI Optimizer](https://github.com/Zion-support/solar-roi-optimizer) sizing; peak-day warnings for [Grid Demand Balancer](https://github.com/Zion-support/grid-demand-balancer).

## Key features
- AutoML model selection per meter with confidence intervals
- API + CSV/utility-data connectors, dashboards, scheduled email/PDF reports
- ESG-ready exports for sustainability reporting
