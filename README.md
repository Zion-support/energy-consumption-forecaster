# 📈 Energy Consumption Forecaster

AI load & usage forecasting for facilities and portfolios. Part of the **Zion Energy & Facilities AI Suite (Batch 72)**.

## What it does
- Forecasts kWh/kW at meter, building and portfolio level (hourly → yearly horizons)
- Weather, calendar and occupancy-aware models
- Budget vs. actual tracking with anomaly alerts
- Baselines for M&V and for [Building Efficiency Auditor](https://github.com/Zion-support/building-efficiency-auditor) savings validation

## Key features
- AutoML model selection per meter with confidence intervals
- Peak-day warnings for demand-charge management (feeds [Grid Demand Balancer](https://github.com/Zion-support/grid-demand-balancer))
- Load profiles for [Solar ROI Optimizer](https://github.com/Zion-support/solar-roi-optimizer) sizing
- API + CSV/utility-data connectors
